Connect to Belfort on your computer

Research, Learn, Practice and News run in the Belfort app on your Windows computer. Start it there, then enter its address. The phone and the computer must be on the same Wi-Fi.

How to find the address
  1. On the computer, start Belfort so the phone can reach it:
    .venv\Scripts\python -m uvicorn belfort.main:app --host 0.0.0.0 --port 8766
  2. Set an access code first, so only you can open it: $env:ACCESS_CODES = "your-code". Belfort asks for it on the phone.
  3. The address is http:// + the computer's Wi-Fi IP (Settings, Network, Wi-Fi, Properties) + :8766.

Tip Check, on this phone

Paste a tip from WhatsApp or Telegram. These checks read only the text and work without the computer or the internet. Connect to Belfort to also check NSE's surveillance lists and the price.

Belfort is free, open-source software for learning. It never says what to buy or sell, and practice uses virtual points only.
